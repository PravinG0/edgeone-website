# EdgeOne – IoT Infrastructure & Edge Intelligence Platform

Enterprise-grade IoT infrastructure and edge intelligence platform. Connect devices, process data at the edge, and deliver real-time operational intelligence.

## Getting Started

### Prerequisites

- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

Follow these steps to set up the project locally:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd edgeone-ascend

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

You can deploy this project using any modern web hosting provider that supports Vite/React applications (e.g., Vercel, Netlify, Cloudflare Pages).

```sh
# Build the project
npm run build
```

The output will be in the `dist` directory.
